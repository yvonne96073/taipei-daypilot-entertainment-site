# Taipei DayPilot v9 Preview Channel

This branch is an isolated preview artifact channel for v9 development.

The stable public site remains the `main` branch at:

`https://yvonne96073.github.io/taipei-daypilot-entertainment-site/`

The `v9-preview` branch must not be promoted to the stable public channel until the v9 release gates pass:

- all snapshot winners have official or explicit evergreen provenance;
- fixture-leak, same-origin API, schema-version, freshness, and image checks pass;
- API and browser regressions pass;
- desktop/mobile screenshot QA passes;
- human-style click acceptance covers modes, duration, CTA, correction, origin, and activity detail;
- original Azure Production remains unchanged.

Preview source is tracked in the `v9-preview` branch of `yvonne96073/taipei-daypilot-entertainment`.
